Banner
Screen title — "CHARACTER SELECT". Static.
Character List
Vertical list of saved characters. One row per slot.
Row content: name · class · Lv.N · playtime.

D-pad ↑/↓ moves selection. Wrap at ends.
Empty slots render as "(Empty Slot)" pills, also selectable.
Model Preview
3D model of the highlighted character.
Idle anim, slow turntable rotation.
Empty slot → silhouette / placeholder.
Description
Class summary + key stat callouts (e.g. "FOmar — male Force, balanced caster, ATP+ over FOnewearl").
Next
Action button — proceed with the highlighted character (or open Create flow on empty slot).

Behavior

Input flow

[D-pad ↑/↓] ── moves selection in the Character List
                │
                ▼
       (single selection state)
                │
                ├──▶ updates Model Preview (loads the character's model + idle)
                ├──▶ updates Description (class summary text)
                └──▶ updates Next label
                       ├─ filled slot → "Start"
                       └─ empty slot  → "Create"

[A / Accept]  ── on filled slot: confirm → enter game with that character
                ── on empty slot: confirm → enter character-create flow

[B / Cancel]  ── back to title screen
[Y / extra]   ── (TBD) delete-character flow, separate concern (issue #168 out-of-scope)

Data shape per row

  • name — display string, max ~12 chars
  • class — short label (HUmar, RAcast, etc.)
  • level — integer
  • playtime — formatted "HHh MMm" or "MMm" if <1h
  • model_id — feeds the preview pane (loaded lazily on selection change)
