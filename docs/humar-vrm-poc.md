# HUmar VRM experiment

The HUmar experiment has been expanded to all 14 playable classes and all four variants. VRM is now the production player-model path, including character creation and selection previews.

See [Character VRM policy and migration guide](character-vrm-policy.md) for conversion, validation, isolated launch commands, NPC migration requirements, distribution steps and the roadmap for moddable avatars. The launcher retains its historical `run_humar_vrm_poc.py` name and now accepts `--class-id`, `--variation`, `--all` and `--gallery`.
